## Investigated a shipwright tooltip and missing translations

User asked about a tooltip screenshot showing a raw internal code (`creature-shipwright:boat-punter-oak-selectionbox-FrontDecoAP`) instead of a readable name while looking at the Punt boat's front decoration attachment point. Checked every boat entity file in the mod for the same gap:
- **`LPlaqueAP`** (nameplate slot) has no lang entry at all — affects Punt, Catboat, Drakkar, and Large Junker.
- **`PassengerSeat1AP`–`PassengerSeat6AP`** on the Large Junker aren't matched by the existing `*selectionbox-*SeatAP` wildcard, since that pattern requires the name to end literally in "SeatAP" and these have a digit before "AP".
- **`FrontDecoAP`** appears unique to the Punt boat.

Confirmed via searching every other installed mod's zip contents that no other mod touches `punter.json` or defines `FrontDecoAP` — the attachment point and the missing translation are both entirely shipwright's own.

No dedicated GitHub repo found for shipwright (its 3 identifiable authors' public GitHub accounts don't host it); the mod page's only homepage link is a Discord channel. Not yet posted — up to the user.
